## Projeto Context Atlas

Context Atlas é uma biblioteca open source que integra o protocolo MCP às APIs da Anthropic para persistência de contexto em agentes de IA.

Objetivos do projeto:

- Persistência de contexto entre execuções de agentes.
- Estruturação do conhecimento em grafos.
- Integração com Claude.
- Facilitar o desenvolvimento de agentes inteligentes utilizando Model Context Protocol.

Tecnologias utilizadas:

- TypeScript
- Node.js
- Anthropic API
