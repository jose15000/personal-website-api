## Projeto LioApply

LioApply é uma aplicação Full Stack para automatizar o processo de candidatura a vagas.

Características:

- Frontend em React e Next.js.
- Backend em Node.js.
- APIs REST.
- PostgreSQL.
- MongoDB.
- Redis.
- Docker.
- Testes automatizados.
